# American English

The migration is implemented. Files, identifiers, owned data keys, comments,
and authored prose use American English. Stored keys and published paths move
forward with the source.

[`STYLE.md`](../../STYLE.md#american-english) owns the spelling policy.
[`pnpm spelling:check`](../../docs/guides/development.md) enforces identifier
spelling as part of `pnpm check`; `pnpm spelling` remains the inventory report.
[The build log](../../CONTEXT.md#american-spelling-reaches-the-stored-keys-12-sep-2026)
records the data boundaries and dictionary failures the migration uncovered.
